# Contributing

Thanks for your interest in **Contract Reviewer Agent Eval**.

## How to contribute

- Add or improve test cases under `data/test_cases/` with clear expected signals
- Keep skills changes reviewable and documented
- Prefer mock-mode verification (`python scripts/run_eval.py`) before live runs

## Pull requests

1. Fork (or branch) from `main`
2. Keep changes focused (docs, fixes, or one feature)
3. Update README / docs if behavior or setup changes
4. Open a PR with a short summary of *why*

## Code of conduct

Be respectful. This project is maintained by a small team; clear, kind feedback helps most.
